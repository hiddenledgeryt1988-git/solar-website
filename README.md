### WhatsApp link behaviour

## 7. Technical implementation

Use a modern, maintainable frontend. Recommended default stack: -
React + TypeScript. - Vite. - Tailwind CSS or a well-structured CSS
system. - Lucide icons or another consistent icon set. - Framer Motion
only where motion materially improves the experience.

If the Antigravity workspace already has a stack or project scaffold,
inspect it first and preserve the existing working setup. Do not replace
project configuration unnecessarily.

### Code quality

-   Build reusable components: Header, Hero, SectionHeading,
    ServiceCard, ProjectCard, FAQAccordion, WhatsAppButton, EnquiryForm,
    Footer.
-   Keep data (services, FAQs, projects, contact details) separate from
    presentation.
-   Use semantic HTML and accessible labels.
-   Ensure keyboard navigation, visible focus states, sufficient
    contrast and reduced-motion support.
-   Avoid oversized dependencies and unnecessary libraries.
-   Keep components readable and easy to edit.
-   No dead buttons, fake forms, broken anchors or placeholder links
    presented as working features.

### Responsive behaviour

-   Mobile-first implementation.
-   Test at 360px, 390px, 430px, tablet, laptop and large desktop
    widths.
-   No horizontal overflow.
-   Use appropriately cropped responsive images.
-   Maintain readable text and touch targets.
-   Mobile nav, cards, forms and accordions must work with touch.
-   Optimise image loading and avoid layout shifts.

### Performance and SEO

-   Optimise images (WebP/AVIF where possible), use responsive sources
    and lazy-load below-the-fold images.
-   Preload only the true hero asset.
-   Set page title, meta description, canonical URL when domain is
    known, Open Graph metadata and favicon.
-   Use descriptive alt text.
-   Add LocalBusiness/Organization structured data only with verified
    business details.
-   Use descriptive headings and natural search terms; do not
    keyword-stuff.
-   Ensure HTTPS on deployment.

### Analytics and privacy

-   Do not add tracking pixels or analytics without owner approval and
    appropriate privacy notice.
-   If analytics are added later, track WhatsApp CTA clicks without
    collecting message contents or sensitive form values.

## 11. Developer & Deployment Guide

### Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Production build & type check:**
   ```bash
   npm run build
   ```
   Generates optimized production assets in the `dist/` directory.

4. **Preview production build locally:**
   ```bash
   npm run preview
   ```
